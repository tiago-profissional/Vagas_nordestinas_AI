# Vagas Nordestinas AI

AI-powered job board and resume optimization platform built with Next.js, TypeScript, Zustand and Google Gemini API.

## Features

- Job board dashboard
- Resume upload
- PDF text extraction
- AI resume analysis with Gemini
- Skills detection
- Resume score
- Candidate profile insights

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Zustand
- Google Gemini API

## Getting Started

```bash
yarn install
yarn dev
